Stack: React Native (Expo & Expo Web) + PHP (Laravel REST API) + MySQL

2. Core Calculations & Business Logic

A. Special Per-Day Withholding Tax Formula (Agency / Hospitality Staff)

Under Japanese Tax Law (Article 204), talent/performer earnings are calculated as follows:

deductible_base = 5000 * attendance_days;
if (gross_revenue > deductible_base) {
    withholding_tax = Math.floor((gross_revenue - deductible_base) * 0.1021);
} else {
    withholding_tax = 0;
}

B. Mixed Expense Splitting (Business Ratio / 家事按分)

When an expense is shared between business and personal life (e.g. Rent: ¥100,000 with 40% business ratio):

  • Business Expense (Rent) = ¥100,000 * 40% = ¥40,000 → Profit & Loss (P/L)
  • Personal Living Cost (Owner's Draw) = ¥100,000 * 60% = ¥60,000 → Balance Sheet (B/S)

C. Estimated Tax Liability Calculation (Home Dashboard)

net_profit = total_sales - total_business_expenses;
blue_declaration_deduction = 650000; // Special Blue Return Deduction
basic_deduction = 480000;            // Basic Personal Deduction
taxable_income = Math.max(0, net_profit - blue_declaration_deduction - basic_deduction);

// Simplified Tax Estimates for User Display:
estimated_income_tax = Math.floor(taxable_income * 0.05);   // Progressive minimum bracket (5%)
estimated_resident_tax = Math.floor(taxable_income * 0.10); // Standard flat 10%
total_estimated_tax = estimated_income_tax + estimated_resident_tax;
