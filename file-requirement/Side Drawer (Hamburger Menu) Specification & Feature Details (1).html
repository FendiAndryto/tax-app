Side Drawer (Hamburger Menu) Specification & Dynamic UI Architecture

Target Architecture: React Native (Expo) Modal Drawer + Laravel API Backend

Public Business Mode Order & Strict Dynamic Visibility:
1. General Freelancer & Sole Proprietor Mode (MODE_FREELANCE) [DEFAULT / PRIMARY]
Creators, IT engineers, designers, consultants, small business owners.
→ Fully standard accounting view. "POS Sync" is completely HIDDEN to avoid confusion.

2. Hospitality & Partner Nightwork Mode (MODE_NIGHTWORK) [SPECIALIZED TRACK]
Venue staff, cast, hospitality performers with partner club/store integrations.
→ Displays "Partner POS Connection", Article 204 withholding tax, and dedicated expense presets.

Category A: Daily Bookkeeping & Automation Rules (仕分け・自動化設定) Phase 1 (P0 Priority)

Item Name Mode Visibility Functional Scope & Logic User Inputs & Action
1. Partner POS Connection
提携店舗POS連携設定		 Nightwork Mode ONLY
(Hidden in Freelance Mode)		 Pairs staff profile with venue/agency POS. Fetches automated daily/monthly attendance payout webhooks via POST /api/v1/pos/sync. Store ID, Cast Code, and 1-time Pairing Token. Shows real-time sync status.
2. Business Ratio Defaults
家事按分初期設定		 All Modes Stores default deductible percentage split for mixed personal/business expenses (Rent, Internet/Phone, Utilities, Vehicle). Auto-sets the split slider on entry. Sliders (0% - 100%) for recurring categories. Saves to user_business_ratios table.
3. Auto-Categorization Rules
自動仕分けルール設定		 All Modes Rule matching engine. Incoming OCR receipts matching specific keywords are automatically categorized and assigned split % without manual swiping. Keyword (e.g., "Adobe", "Seven-Eleven"), Target Category, Split %, Priority order.
4. Notification Reminders
リマインド通知設定		 All Modes Configures recurring local push notifications reminding users to capture backlog receipts and complete transaction swiping. Toggle ON/OFF, day-of-week selectors (Mon-Sun), and time picker (e.g., 20:00).

Category B: Master Catalogs & Assets (マスタ管理・固定資産) Phase 2 (P1 Priority)

Item Name Mode Visibility Functional Scope & Logic User Inputs & Action
5. Client Directory
取引先マスタ管理		 All Modes Directory of recurring agencies, clients, or billing entities. Auto-populates recipient details when issuing invoices. Client Name, Address, Contact, Qualified Invoice Registration Number (T-number).
6. Invoice Issuer Profile
インボイス発行設定		 All Modes Configures user's Qualified Invoice Issuer ID (T + 13 digits) and statutory rounding settings (Single-pass floor/ceil/round). T-Number input with format validation, default payment bank account, rounding method selector.
7. Fixed Asset Ledger
固定資産台帳 (減価償却)		 All Modes Manages capital equipment exceeding ¥100,000 (e.g., laptops, smartphones, vehicles). Calculates annual depreciation schedules (Straight-Line or Small-Sum <¥300,000). Asset name, Purchase date, Cost, Useful life years, Depreciation method.

Category C: Annual Tax Return & Fiscal Forms (確定申告・税務書類) Phase 3 (P2 Priority)

Item Name Mode Visibility Functional Scope & Logic User Inputs & Action
8. Tax Return Wizard
確定申告書作成		 All Modes Annual interactive questionnaire evaluating tax deduction eligibility (Basic Deduction ¥480,000, Spouse, Dependents, Social Insurance, Medical). Yes / No / Unsure cards. Saves answers into user_tax_profiles table.
9. Generate Official PDF
申告書類プレビュー		 All Modes Aggregates annual transaction data and wizard answers. Maps values directly onto official Japanese National Tax Agency forms: Form B (第一表・第二表) and Blue Return Statement (青色申告決算書). PDF viewer modal with "Download PDF" and "Share" actions.
10. Fiscal Year Switcher
会計年度の切り替え		 All Modes Switches active accounting period (e.g., 2026 / 2025). Re-fetches transactions and reports corresponding to the selected fiscal year. Wheel picker modal with active year badge.

Category D: Data Migration & Backup (データ連携・入出力) Phase 4

Item Name Mode Visibility Functional Scope & Logic User Inputs & Action
11. CSV Data Import
他社データ取り込み		 All Modes Migrates accounting data from other software (freee, MoneyForward, Yayoi, PayPay CSV). Parses standard formats and inserts into transactions table. File picker (CSV upload), Source software dropdown, Mapping preview button.
12. CSV Data Export
取引データエクスポート		 All Modes Exports transaction records for tax accountants or backup purposes. Generates Journal Ledger (仕訳帳) and General Ledger (総勘定元帳). Fiscal year selector, Encoding picker (UTF-8 or Shift_JIS for Excel), Export button.

Category E: Account & Settings (アカウント・設定) Phase 5

Item Name Mode Visibility Functional Scope & Logic User Inputs & Action
13. Business Mode & Profile
業種・働き方設定 & プラン		 All Modes Switches active business mode: 1. General Freelancer vs 2. Nightwork & Hospitality. Updates personal info and manages subscription. Mode selector radio toggle, Email update, subscription management.
14. Support & Terms
利用規約・ログアウト		 All Modes Legal terms of service, privacy policy, app version information, and secure logout action. Links to terms webview, logout trigger button.
