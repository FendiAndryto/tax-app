Side Drawer Navigation & UI Screen Transition Specification

Target Stack: React Navigation (Drawer / Stack / BottomSheet) + Expo + Laravel API

Architecture & Role Visibility Rules:
• Order Rationale: Ordered by user mental model (1. Expense Rules → 2. Billing & Masters → 3. Annual Tax Filings → 4. Electronic Storage & Data → 5. System Settings).
• General Freelancer Mode (MODE_FREELANCE) [Default]: Item 6 (Partner POS & Auto-Invoicing) is completely HIDDEN to maintain a clean standard bookkeeping UI.
• Nightwork & Store Mode (MODE_NIGHTWORK): Item 6 is visible, enabling venue POS sync and automated invoice delivery to the store console.

1. Stack Screen (Full Screen Push)

Used for heavy data forms and lists. Native back navigation (< Back) without keyboard overlap.

2. BottomSheet (Half Modal)

Used for fast 1-to-2 tap selections (pickers, exports, toggles). Keeps parent context visible.

3. Full Modal (Focused Flow)

Used for multi-step tax filing wizards and official PDF viewers. Hides bottom tabs to keep user focused.

Automated Store Invoicing & Electronic Storage Architecture

ERPA Compliance & Dual-Platform Workflow:
1. Cloud Server Storage: Every receipt OCR image and generated Invoice PDF is stored in secure S3/cloud storage with immutable SHA-256 hash timestamps.
2. 7-Year Retention: Records remain accessible for 7 statutory years to protect users during tax audits.
3. ERPA Search Requirements: The Electronic Storage Box (Item 10) supports filtered queries combining Date, Amount, and Client Name without downloading raw files.
4. Store Console Sync: Invoices issued to stores are mirrored directly in the Store Console's audit archive.

Subscription Cancellation vs. Account Deletion Architecture (解約・退会仕様)

Crucial Rule for Indonesian Backend & UI Team:
Do NOT delete user data upon subscription cancellation. Follow the strict 2-tier lifecycle below:
User Action System State & Permission Data Retention & UI Behavior
1. Subscription Cancel
有料プラン解約 (無料プラン移行)		 subscription_status = 'canceled'
access_mode = 'READ_ONLY_ARCHIVE' 		• New Entries Blocked: Scanning OCR and new auto-sync features are locked.
• 7-Year Data Maintained: All past receipts, invoices, and journal books remain viewable & searchable in Item 10 (Electronic Storage Box).
• Full Export Allowed: User can download past ZIP archives and CSV files anytime to prevent tax audit penalties.
2. Account Hard Deletion
退会 (アカウント完全消去)		 deleted_at = NOW()
purge_scheduled_at = NOW() + 30 Days 		• Mandatory Export Prompt: Warns user of the 7-year legal tax storage requirement and prompts full ZIP download.
• Legal Disclaimer Checkbox: User must check [✓] I understand my past tax records will be permanently erased and cannot be used in tax audits.
• 30-Day Soft Delete: Data is retained in quarantine for 30 days before permanent AWS S3 purge to allow recovery from accidental deletion.
