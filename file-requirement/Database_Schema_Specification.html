Database Schema Specification (MySQL 8 / Laravel 11)

System: AUBE TERRA / MYBRAIN Accounting & Tax Automation Engine

Key Architectural Principles:
1. Double-Entry Journaling: Every transaction generates balanced Debit and Credit entries in journal_entries.
2. ERPA Compliance (電子帳簿保存法): Receipts and Invoices are tracked in erpa_documents with SHA-256 hashes, immutable timestamps, and statutory composite index (issue_date, amount, partner_name) for 7-year audit inquiries.
3. Article 204 Withholding Tax Support: Tracks daily allowances and tax deductions specifically for nightlife & freelance payouts.
4. Subscription Lifecycle: User accounts support READ_ONLY_ARCHIVE mode upon cancellation, retaining 7-year ERPA data.

1. Entity Relationship Overview

[ users ]
    │──< [ user_business_ratios ] (Apportionment presets: rent, utilities, wifi, car)
    │──< [ auto_categorization_rules ] (Keywords -> category matching)
    │──< [ transactions ]
    │       │──< [ journal_entries ] (Double-entry: Debit & Credit lines)
    │       └──1 [ erpa_documents ] (Receipt OCR images / Invoice PDFs with SHA256)
    │──< [ pos_sync_logs ] (Nightwork store synchronization logs)
    │──< [ invoices ] (Generated Qualified Invoices with T-number)
    └──< [ tax_filing_summaries ] (Annual Form B / Blue Return snapshots)

2. Table Schema Definitions

1. users (User Accounts & Tax Profiles)

Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Auto-incrementing primary key.
business_mode ENUM 'MODE_FREELANCE' or 'MODE_NIGHTWORK'. Controls POS menu visibility.
email VARCHAR(255) UNIQUE User email address.
password VARCHAR(255) Bcrypt hashed password.
t_number VARCHAR(14) NULLABLE National Tax Agency Qualified Invoice Issuer number (e.g., T1234567890123).
tax_rounding_rule ENUM DEFAULT 'FLOOR' 'FLOOR' (切り捨て), 'ROUND' (四捨五入), 'CEIL' (切り上げ).
subscription_status ENUM DEFAULT 'TRIAL' 'TRIAL', 'ACTIVE', 'CANCELED', 'DELETED'.
access_mode ENUM DEFAULT 'FULL' 'FULL', 'READ_ONLY_ARCHIVE' (Active on cancellation; unlocks 7-year storage).
created_at / updated_at TIMESTAMP Laravel default timestamps.
deleted_at TIMESTAMP NULLABLE Soft delete timestamp (30-day quarantine before purge).

2. user_business_ratios (家事按分初期設定 / Drawer #1)

Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Primary key.
user_id BIGINT UNSIGNED FK Foreign key referencing users.id (CASCADE).
expense_type ENUM 'RENT' (家賃), 'ELECTRICITY' (電気代), 'INTERNET' (通信費), 'VEHICLE' (車両費).
monthly_estimated_cost DECIMAL(10,2) DEFAULT 0 Monthly base expenditure amount in JPY.
business_percentage DECIMAL(5,2) Business use ratio from 0.00% to 100.00% (slider value).
target_account_id BIGINT UNSIGNED FK Default expense account (e.g., 地代家賃, 水道光熱費, 通信費).

3. account_categories (勘定科目マスタ)

Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Primary key.
code VARCHAR(10) UNIQUE Account code (e.g., 111 Cash/Bank, 411 Sales, 521 Styling).
name_ja VARCHAR(100) Japanese account name (e.g., 会議費, 旅費交通費, 美容衛生費).
name_en VARCHAR(100) English account name.
type ENUM 'ASSET', 'LIABILITY', 'EQUITY', 'REVENUE', 'EXPENSE'.
is_nightwork_preset BOOLEAN DEFAULT FALSE True if specifically tailored for nightlife casts (e.g., 衣装代, ヘアメイク代).

4. transactions (Header Record for Bookkeeping & Swipes)

Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Primary key.
user_id BIGINT UNSIGNED FK Foreign key referencing users.id.
transaction_date DATE INDEX Date of payment or revenue receipt.
amount DECIMAL(12,2) INDEX Gross transaction amount in JPY.
partner_name VARCHAR(255) INDEX Store / Client name (e.g., "Starbucks Coffee", "GO Taxi App").
source_type ENUM 'ocr' (Camera), 'manual' (User entry), 'pos' (Store sync), 'bank', 'credit_card'.
status ENUM INDEX 'pending_review' (Tab 2 swipe queue), 'confirmed' (Balanced into ledger), 'excluded' (Private).
confidence_score DECIMAL(3,2) NULLABLE AI OCR/Category classification score (0.00 - 1.00). Used for 1-tap Batch Confirm.

5. journal_entries (複式簿記仕訳データ / Double-Entry Ledger)

Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Primary key.
transaction_id BIGINT UNSIGNED FK Foreign key referencing transactions.id (CASCADE).
account_category_id BIGINT UNSIGNED FK Referencing account_categories.id.
entry_type ENUM 'DEBIT' (借方) or 'CREDIT' (貸方).
amount DECIMAL(12,2) Debit/Credit breakdown amount. Sum(Debit) must strictly equal Sum(Credit).
tax_rate DECIMAL(4,2) DEFAULT 0.10 Consumption tax rate applied (0.10 for 10%, 0.08 for 8%, 0.00 for exempt).

6. erpa_documents (電子帳簿保存法 証憑ストレージ / Drawer #10)

Statutory ERPA Compliance Index:
The composite index idx_erpa_search (user_id, issue_date, amount, partner_name) is legally mandatory to satisfy the National Tax Agency's 3-key range query audit rules.
Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Primary key.
user_id BIGINT UNSIGNED FK Foreign key referencing users.id.
transaction_id BIGINT UNSIGNED FK Nullable foreign key referencing transactions.id.
document_type ENUM 'RECEIPT' (Scanned slip) or 'INVOICE' (Delivered qualified invoice).
issue_date DATE COMPOSITE Document date stated on the receipt/invoice.
amount DECIMAL(12,2) COMPOSITE Total monetary value.
partner_name VARCHAR(255) COMPOSITE Issuer / vendor name.
storage_path VARCHAR(512) S3 bucket relative path (e.g., erpa/2026/08/doc_9012.jpg).
file_sha256 CHAR(64) SHA-256 cryptographic hash generated at the exact upload second (anti-tamper verification).
statutory_retention_until DATE Calculated retention date (Fiscal year close + 7 statutory years).

7. pos_sync_logs (店舗POS連携・給与台帳同期ログ / Drawer #6)

Column Name Data Type Key / Index Description / Rules
id BIGINT UNSIGNED PK Primary key.
user_id BIGINT UNSIGNED FK Foreign key referencing users.id.
pos_transaction_id VARCHAR(100) INDEX External store POS reference (e.g., POS-202610-8812). Prevents duplicate syncs.
pay_period VARCHAR(7) Payroll year-month (e.g., 2026-09).
attendance_days SMALLINT UNSIGNED Days worked in period. Used to calculate Article 204 base deduction (¥5,000/day).
gross_revenue DECIMAL(12,2) Gross earnings before withholdings.
withholding_tax DECIMAL(12,2) Tax withheld under Article 204: (Gross - (5000 × Days)) × 10.21%.
net_payment DECIMAL(12,2) Net payout transferred to cast.
deductions_json JSON Serialized breakdown array (Hair-make, locker, late penalties, advance loans).
