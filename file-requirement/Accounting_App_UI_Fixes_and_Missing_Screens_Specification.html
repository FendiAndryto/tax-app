Accounting App UI/UX Fixes & Missing Screens Specification

Target Stack: React Native (Expo) / Laravel 11 API / Figma App Shell

Task Objective for Development Team:
This document outlines the required UI adjustments on existing Tab screens and provides full specifications for the unbuilt screens (P0 / P1) required for commercial production release.

1. UI & Interaction Fixes for Existing Screens (3 Core Fixes)

Target Component Category Current Issue Actionable Fix Instructions
Bottom Navigation Bar
(5-Tab Bar)		 UI Text Polish Labels such as "レシート撮影" and "事業レポート" have excessive character length, risking overflow on compact screens. Standardize all tab labels to concise 2–4 Japanese characters:
ホーム | 仕分け | 撮影 (Center 56px action) | 取引・請求 | レポート
Tab 2: Journaling Screen
(Swipe Bookkeeping)		 Batch UX & Undo Only allows sequential 1-by-1 card swipe. Lacks batch confirmation for accumulated backlogs and quick recovery. 1. Batch Confirm Button: Add ⚡ AI判定を信じて全◯◯件を一括確定 (Confirm All Remaining via AI) beneath the card stack.
2. Immediate Undo Toast: Display a floating snackbar ↩ 1件元に戻す (Undo) for 4 seconds after each swipe.
Tab 4: Transactions Screen
(Timeline List)		 Inline Edit & ERPA Modifying an account category requires pushing a detail screen. Document storage status is not visible at a glance. 1. Inline Category Switch: Tapping the category badge (e.g., [ 消耗品費 ▾ ]) opens a BottomSheet to reassign and save in 1 tap without page transition.
2. ERPA Compliance Badge: Display a small 📎 or 📄 icon on rows with verified cloud receipts/invoices.

3. Subscription Cancellation vs. Account Hard Delete Policy

User Action System State Retention Policy & UI Behavior
Paid Plan Cancel
(Free Archive Mode)		 subscription_status = 'canceled'
access_mode = 'READ_ONLY_ARCHIVE'		 New OCR scans and automated POS syncing are locked. Past 7-year records remain viewable & searchable in Screen D-10 with full ZIP download capability.
Account Hard Deletion
(Full Purge Request)		 deleted_at = NOW()
purge_scheduled_at = NOW() + 30 Days		 Mandates full ZIP backup download, enforces ERPA legal disclaimer confirmation checkbox, and holds data in soft-delete quarantine for 30 days before permanent AWS purge.
